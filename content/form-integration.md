# Форма ROCCA

Сейчас форма готовит письмо на подтверждённый адрес info@granit47spb.ru. Данные не отправляются с сайта; выбор файлов убран, чтобы не создавать ложного ожидания передачи.

Для серверной отправки нужны: почтовый сервис/API, подтверждённый отправитель, адрес получателя, серверные переменные окружения и решение для вложений (либо ограниченные email-вложения, либо временное защищённое хранилище). После подключения: несколько файлов PDF/DWG/DXF/JPG/PNG, лимиты размеров и количества, проверка типов на сервере, защита от спама, обработка ошибок, ограниченное хранение. Сообщение об успешной отправке допустимо только после подтверждённого принятия заявки сервером.
